# Port the gve-robin design system into Learn Wren — Design

**Date:** 2026-07-24
**Status:** Approved (brainstormed with user; port everything, full sweep)

## Goal

Bring the component machinery of the gve-robin UI workspace (local copy at
`/Volumes/2002/slim-editorial-src/ui`) into the Learn Wren monorepo, restyled
onto Learn Wren's existing `--lw-*` visual identity, and migrate all Learn
Wren web UI onto it. Learn Wren keeps its look (cyberpunk-noir dark default,
warm-paper light, ochre accent, serif headings); it gains robin's component
depth, a11y behavior, token pipeline, and testing discipline.

gve-robin is the **example/donor** only. Nothing is pushed to or changed in
any robin remote; the port is a one-way copy-and-restyle into this repo.

## What is ported (everything)

| Robin source | Learn Wren destination | Notes |
|---|---|---|
| `libs/shared/ui` (~50 spartan-ng/hlm components + specs) | expanded `libs/web-ui` | Behavior, selectors, inputs/outputs kept; style strings re-expressed in `--lw-*` tokens/utilities |
| `libs/shared/design-system` (Style Dictionary pipeline, AAA-contrast gate, token lint, fonts) | new `libs/web-design-system` | Learn Wren's hand-written `libs/web-ui/src/styles/tokens.css` becomes generated output of token sources emitting the **same `--lw-*` names** |
| `libs/shared/data-table` (TanStack table + virtual scroll) | new `libs/web-data-table` | Ported last (slice G); no current consumer, first use is opt-in |

Learn Wren's existing 10 `web-ui` primitives (avatar, button, card, cover,
icon, input, pill, progress, theme, theme-toggle) are superseded by hlm
equivalents where one exists; `theme`/`theme-toggle` (and any primitive
without an hlm equivalent, e.g. `cover`) are kept.

## New dependencies

`@spartan-ng/brain`, `@ng-icons/core` + `@ng-icons/lucide`,
`@tanstack/angular-table` + `@tanstack/angular-virtual` (slice G),
`style-dictionary` (dev). Angular ~21.2 on both sides — no framework delta.
`@angular/cdk` already present (overlay-prebuilt.css must be imported).

## Tailwind 3 → 4 upgrade (slice A)

Learn Wren is on Tailwind 3; robin's lib and token wiring are Tailwind 4
CSS-first (`@theme inline`). Learn Wren upgrades to Tailwind 4 as part of
slice A rather than backporting the token bridge to a v3 JS config:
the sweep re-touches every template anyway, and a v3 bridge is throwaway.
The upgrade is the one piece with risk outside the design system; it lands
as a visual no-op verified by the existing e2e suites.

## Token architecture

- Token sources (primitives + semantic) emit exactly the `--lw-*` vocabulary
  already in `tokens.css` — core (`--lw-bg/-2/-3`, `--lw-line/-2`,
  `--lw-ink…ink-4`, `--lw-ochre/-2/-ink`, `--lw-moss/clay/rust`,
  `--lw-good/warn/bad`, fonts, radii `--lw-r-*`, shadows, density) — so
  slice A is a rename-free, visual no-op.
- Component-scoped roles arrive with the components in slice B (`--lw-button-*`,
  `--lw-input-*`, `--lw-dialog-*`, …) with values pointing at the lw core,
  following the robin-side mapping table
  (`/Volumes/2002/slim-editorial-src/docs/design-system/2026-07-24-lw-design-system-adoption-design.md`).
- Dark stays the default; `[data-theme='light']` carries warm-paper values.
  The AAA contrast gate covers both themes.

## Slices (each lands green, in a worktree, merged --no-ff to main)

- **A. Tailwind 4 + token pipeline** — upgrade Tailwind, add
  `libs/web-design-system` generating today's `tokens.css` byte-compatibly
  (or provably equivalent), wire `@theme inline` utilities to `--lw-*`,
  contrast gate + token lint on. Visual no-op.
- **B. Component lib** — port hlm components + their specs into
  `libs/web-ui`, restyled onto lw recipes (buttons `bg-ochre/text-ochre-ink`
  primary, inputs `border-line bg-bg focus:border-ochre`, cards
  `bg-bg-2 border-line`, focus ring `2px solid var(--lw-ochre)` offset 2px).
  Showcase route (dev-only) for visual verification.
- **C. web-auth** — first migration pilot inside the sweep.
- **D. web-courses + web-video** — largest surface.
- **E. web-admin** — tables/dialogs-heavy; validates dialog + combobox parity.
- **F. web-landing + apps/web shell** — delete superseded web-ui primitives
  once their last consumer migrates.
- **G. Data-table + gates** — port `libs/web-data-table`; add grep gates
  (no orphaned class names from the old primitives); mutation-testing rounds
  on the new libs per repo standard.

**Verification per slice:** `pnpm nx affected -t lint test typecheck`,
token lint + contrast gate (A onward), Playwright e2e suites for the touched
area, and a browser pass over the showcase/affected pages.

## Success criteria

1. All Learn Wren web UI renders through the ported component lib; the old
   ad-hoc primitives that have hlm equivalents are deleted.
2. `tokens.css` is generated by the pipeline; contrast gate (both themes)
   and token lint run in CI.
3. Tailwind 4 build; no Tailwind 3 config remains.
4. All unit/e2e suites green; new libs reach the repo's Stryker standard in
   scheduled mutation rounds.
5. Visual identity unchanged where not deliberately improved: dark default,
   ochre accent, serif headings.
